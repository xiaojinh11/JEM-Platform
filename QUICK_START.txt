🚀 一键部署 (推荐)
─────────────────────────────────────────────────────────────

bash deploy_secure.sh

此脚本自动完成:
  ✓ 生成生产级密钥 (SECRET_KEY / FERNET_KEY / REDIS_PASSWORD)
  ✓ 更新环境配置 backend/.env
  ✓ 导出 Redis 密码环境变量
  ✓ 执行数据库迁移 (添加审批字段)
  ✓ 启动所有服务 (Postgres / Redis / Backend / Worker / Frontend)

─────────────────────────────────────────────────────────────

📋 手动部署步骤
─────────────────────────────────────────────────────────────

1️⃣  生成密钥
   python backend/scripts/generate_keys.py
   
   将输出的三个密钥追加到 backend/.env:
   SECRET_KEY=<64位hex>
   FERNET_KEY=<44位base64>
   REDIS_PASSWORD=<密码>

2️⃣  导出环境变量
   export REDIS_PASSWORD=<你的密码>

3️⃣  数据库迁移
   docker compose run --rm backend alembic upgrade head

4️⃣  启动服务
   docker compose up -d --build

✅ 部署验证
─────────────────────────────────────────────────────────────

1. 检查服务状态
   docker compose ps
   
   所有服务应显示 "Up" 或 "healthy"

2. 验证 Redis 认证
   redis-cli -h localhost -p 6379 -a <你的密码> ping
   
   预期输出: PONG

3. 测试高危命令检测
   登录后台 → 模板管理 → 创建包含 "shutdown" 的模板
   预览时应显示红色警告: "高危操作检测 - 需要管理员审批"

🆘 常见问题
─────────────────────────────────────────────────────────────

Q: 启动时报错 "UNSAFE KEY DETECTED"?
A: 正常！这是安全校验机制。请运行 deploy_secure.sh 生成新密钥。

Q: 无法连接 Redis?
A: 检查环境变量: echo $REDIS_PASSWORD
   确保 docker-compose.yml 引用了正确的密码。

Q: 任务启动失败 "requires admin approval"?
A: 任务包含高危命令。以管理员身份登录 → 任务详情 → 审批通过。

Q: 前端显示 "Network Error"?
A: 检查后端服务状态: docker compose logs backend
   确认 8000 端口未被占用。
