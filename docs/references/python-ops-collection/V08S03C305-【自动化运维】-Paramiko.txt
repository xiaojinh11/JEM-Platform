Paramiko
Paramiko是一个Python库，主要用于SSHv2协议的连接，支持远程命令执行、文件传输等功能。核心功能包括SSH客户
端和SFTP客户端。可以用于自动化运维、批量管理服务器等场景。
安装paramiko模块：
pip install paramiko==4.0.0  （官方地址安装，安装速度比较慢）
pip install paramiko -i https://pypi.tuna.tsinghua.edu.cn/simple （国内镜像源安装方式）


----- PAGE 8 -----
Paramiko
基本使用方法：
导入模块：
import paramiko #导入模块
建立连接：
ssh_client = paramiko.SSHClient()   #创建SSH客户端
ssh_client.set_missing_host_key_policy(paramiko.AutoAddPolicy())   #添加主机密钥
ssh_client.connect(hostname=ip,username=username,password=passwd,port=22)  #连接设备
建立交互式窗口：
commad = ssh_client.invoke_shell()     #创建交互式窗口
commad.send(‘disp cur\n’)                  #发送数据
读取数据：
output = commad.recv(65535)
print(output.decode('ascii'))
ssh_client.close #关闭ssh连接

----- PAGE 10 -----
Paramiko
Paramiko函数
SSH连接模块：
def ssh_client(device_info):
device_name = device_info['name']
device_ip = device_info['ip']
device_user = device_info['username']
device_passwd = device_info['password']
ssh_client = paramiko.SSHClient()
ssh_client.set_missing_host_key_policy(paramiko.AutoAddPolicy())
ssh_client.connect(hostname=device_ip,username=device_user,password=device_passwd)
print(f"设备登录成功：{device_ip}")
command = ssh_client.invoke_shell()
command.send('disp ip int br \n')
time.sleep(1)
output = command.recv(65535) .decode('ascii')
return output

Netmiko 是基于 Paramiko 构建的多厂商网络设备自动化管理库，专为网络设备（交换机、路由器、防火墙等）的
CLI 自动化而设计。Netmiko 内置了针对不同厂商设备（Cisco、华为、H3C、Juniper 等）的适配逻辑，自动处理提示
符匹配、分页、权限切换等繁琐细节。

创建数据表
在 hw_config 数据库中创建一个名为 config_data 的表（如果该表不存在），表中有三个文本字段：time（时
间）、name（名称）、ip（设备IP地址）、content（内容），并使用 utf8mb4 字符集支持完整的 Unicode 编码。
