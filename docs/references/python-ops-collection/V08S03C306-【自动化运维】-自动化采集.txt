正则表达式
数通设备包含正则表达式命令，在支持正则表达式的命令中，有三种过滤方式可供选择：
disp cur | begin regular-expression：输出以匹配指定正则表达式的行开始的所有行。
disp cur | exclude regular-expression：输出不匹配指定正则表达式的所有行。
disp cur | include regular-expression：只输出匹配指定正则表达式的所有行
说明：regular-expression为字符串（不包括中文）形式，长度范围是1～255

RE模块
Python中re模块主要功能是通过正则表达式是用来匹配处理字符串
re.findall()：
浏览全部字符串，匹配所有合规则的字符串，匹配到的字符串放到一个列表中，未匹配成功返回空列表
注意： 一旦匹配成，再次匹配，是从前一次匹配成功的，后面一位开始的，也可以理解为匹配成功的字符串，不在参
与下次匹配
import re #引入模块
str_1 = ‘www.sichuannuoheng.com’ #定义一个字符串
s1 = re.findall(‘si\w*’,str_1) #匹配‘si’后面的所有字母和数字
print(s1) #s1为[‘chuannuoheng’]


----- PAGE 12 -----
捕获组数量 返回值类型
0个（无括号） 返回所有完整匹配的字符串列表
1个 返回每个匹配中该组内容的列表
2个及以上 返回元组，每个元组包含各组的内容，并形成列表
RE模块
当正则表达式中有捕获组 () 时，findall() 的返回值规则如下：
sys_name = re.findall(‘<(\S+)>’,conf_res)，其中（\S+）为捕获组
例如：
findall() 有3个 () 捕获组，就自动把每次匹配到的3个值打包成一个元组，所有匹配结果再组成一个列表返回。
